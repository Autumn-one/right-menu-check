# Distribution control plane

This directory is the public, signed control plane for RightMenuCheck clients.

- `update-public-key.pem` is embedded into the application and verifies update and announcement payloads.
- `update.json` is generated by the release manager after a GitHub Release asset is uploaded.
- `messages.json` is generated by the release manager when an operator publishes a user notice.

The matching private key lives at `.secrets/update-signing-private.pem`. Both `.secrets/` and
`github-conf.json` are ignored by Git and must never be included in a release package or log.

Clients try the configured domestic mirrors before direct GitHub access. A mirror response is trusted
only after its ECDSA signature validates; update archives must also match the signed size and SHA-256.
